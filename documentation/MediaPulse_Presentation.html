What is MediaPulse?

The Problem

  • Marketing teams manage multiple social media platforms separately
  • No single view to track campaign performance
  • Difficult to analyze audience demographics across platforms
  • No role-based access for team members

Our Solution

  • Unified dashboard for all social media analytics
  • Real-time KPI tracking across Facebook, Twitter, Instagram, LinkedIn
  • Role-based access for 5 different user types
  • Campaign management from creation to completion
  • Audience insights: age, gender, location, device

Project Architecture

Frontend (Angular 17)

  • Components: Login, Signup, Dashboard, Campaigns, Analytics, Audience
  • Services: AuthService, DashboardService, CampaignService
  • AuthGuard — protects private routes
  • JWT Interceptor — auto-injects token
  • Reactive Forms with validation
  • Port: 4200

Backend (Spring Boot)

  • REST Controllers for each module
  • AuthService with BCrypt & JWT
  • Spring Security configuration
  • JPA Entities & Repositories
  • Global Exception Handler
  • Port: 3000

Database (MySQL)

  • 8 tables: users, campaigns, posts, kpis, platforms, audience_insights, reports
  • Pre-loaded mock data
  • Foreign key relationships
  • Role-based user system
  • DB: mediapulse_db

Authentication Flow
1
User visits /signup and fills in Full Name, Email, Password, Role
2
Frontend sends POST /api/auth/register to Spring Boot
3
Backend hashes password with BCrypt and saves to users table
4
User redirected to /login page
5
User enters credentials → POST /api/auth/login
6
Backend verifies BCrypt hash → generates JWT token (7 days)
7
Token stored in localStorage, user redirected to /dashboard
8
All API calls include Authorization: Bearer token automatically

How to Run the Project

Step 1 — Database

mysql -u root -p
source schema.sql

Creates mediapulse_db with all tables and mock data

Step 2 — Backend (Terminal 1)

cd backend-spring
mvn spring-boot:run

Starts at http://localhost:3000

Step 3 — Frontend (Terminal 2)

cd frontend
npm install
npm start

Starts at http://localhost:4200
