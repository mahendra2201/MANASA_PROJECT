1. Project Overview

MediaPulse Insights is a full-stack web application designed for marketing teams to monitor, manage, and analyze their social media campaigns across multiple platforms — Facebook, Twitter, Instagram, and LinkedIn.

The platform provides real-time KPI tracking, audience demographic insights, campaign management, and analytics dashboards — all from a single unified interface.

Core Goals

  • Centralize social media performance data across all platforms
  • Provide role-based access for different team members
  • Track KPIs: likes, shares, comments, impressions, reach, CTR, engagement rate
  • Analyze audience demographics (age, gender, location, device)
  • Manage marketing campaigns from creation to completion

5. Authentication Flow

  1. User visits /signup → fills in Full Name, Email, Password, Role
  2. Frontend sends POST /api/auth/register to Spring Boot backend
  3. Backend validates input, hashes password with BCrypt, saves user to users table
  4. Frontend shows success message → redirects user to /login
  5. User logs in at /login with their credentials
  6. Backend verifies password hash → generates a JWT token (valid 7 days)
  7. Token is stored in localStorage on the browser
  8. All subsequent API requests include the token in the Authorization: Bearer header
  9. Protected routes are guarded by AuthGuard (Angular) and JwtAuthenticationFilter (Spring Boot)

8. How to Run the Project

Prerequisites — Install These First

  • Java JDK 17 — for Spring Boot backend
  • Apache Maven — to build Spring Boot
  • Node.js (v18+) & npm — for Angular frontend
  • Angular CLI — npm install -g @angular/cli
  • MySQL 8.x — database server
  • VS Code or IntelliJ IDEA — IDE

Step 1 — Setup the Database

-- Open MySQL and run:
mysql -u root -p
source C:/Users/Mahendra_Mannem/mediapulse/database/schema.sql

Step 2 — Run the Spring Boot Backend (Terminal 1)

cd C:\Users\Mahendra_Mannem\mediapulse\backend-spring
mvn spring-boot:run

Backend starts at: http://localhost:3000

Step 3 — Run the Angular Frontend (Terminal 2)

cd C:\Users\Mahendra_Mannem\mediapulse\frontend
npm install
npm start

Frontend starts at: http://localhost:4200

Step 4 — Open in Browser

Navigate to: http://localhost:4200

You will land on the Signup page → create an account → redirected to Login → log in → enter Dashboard.

10. Security

  • Passwords hashed using BCrypt (cost factor 10) — never stored in plain text
  • JWT tokens expire after 7 days
  • All protected API routes require Authorization: Bearer <token> header
  • Angular AuthGuard prevents unauthenticated users from accessing protected pages
  • Spring Security JwtAuthenticationFilter validates every incoming request
  • CORS configured to allow only http://localhost:4200
